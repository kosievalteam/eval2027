# 평가이력카드 프로토타입 (계속평가 사업 평가이력제 신설안)

□ 계속 평가 사업의 연도별 지적사항·개선 여부를 한 장의 이력카드로 정리하여 평가위원에게 제공하는 시안

○ 카드 구성(5개 절): 사업 개요 → 등급 추이(’19~’26) → 전년도 권고 ↔ 금년도 이행실적 대비 → 반복 지적·미개선 사항 → 평가위원 확인 사항
 - 등급 추이는 '중소기업 지원사업 성과평가' 행 아래에 '타 재정사업평가제도' 행(열린재정 재정사업평가결과 중 통합재정사업평가·일자리·재난안전·국가균형발전·복권기금 등, 중소기업지원사업평가는 제외)을 제도별로 배치하고, 열린재정 수록 중소기업지원사업평가 결과와 본 등급의 정합성은 각주로 대조
 - 권고↔이행 대비는 저성과(미흡·개선필요) 연도별로 좌측 평가보고서 원문(지적·권고), 우측 부처 회신(이행조치·완료일)을 대응
 - 반복 지적은 연도 간 지적 제목·내용의 문자 2-gram 유사도(0.28 이상) 또는 공통 핵심어로 자동 탐지한 후보를 제시
 - 확인 사항은 카드 데이터에서 자동 생성(최근 저성과 권고 이행, 저성과 사유 동일성, 등급체계 개편, 분야 변경, 열린재정 불일치, ’26년 통합재정사업평가 결과, 타 제도 저성과 이력)
 * 샘플: 중소벤처기업부 마케팅지원사업(세부사업 3612300) — ’19·’21 미흡, ’25 개선필요, 미흡횟수 3회. 지적·권고·이행조치는 서식 시연용 **예시 문안**(`data/sample_findings_3612300.json`)으로 채우고 카드에 '예시' 표식·안내 배너를 표시

○ 자료 범위와 한계
 - 등급·분야·미흡횟수: 「(’19~’26년) 개선필요사업_등급추이_노란음영수정」 xlsx(99개 사업)
 - 지적·권고 및 이행조치·완료일: 「(2026.10.12) 저성과 사업_개선사항 파악_부처별정리_261023수합본」 hwp(34개 사업·연도, ’23~’25 평가분)
 - 수합본에 중소벤처기업부 회신분이 없어 마케팅지원사업의 ’19·’21·’25년 지적·권고·이행조치는 가상의 예시 문안으로 채움. 실제 평가보고서 원문·부처 회신을 `history.json` 형식으로 입력하면 `build_card.py`가 예시 대신 실제 데이터를 사용(실제 데이터가 있는 연도에는 예시를 넣지 않음)
 - 이행조치 미회신 10건(문체부 6, 농림부 3, 금융위 1)은 '이행조치 미회신'으로 표시
 - 열린재정 재정사업평가결과(’19~’26, 7,086행)는 세부사업명·소관 기준으로 99개 중 94개 사업에 결합. 미결합 5개는 열린재정에 동일 사업명이 없는 사업
  * 마케팅지원사업: 중소기업지원사업평가 ’21 미흡·’22~’24 보통·’25 개선(=개선필요), 통합재정사업평가 ’26 사업개선(유형 보조사업·중소기업)

## 파일

| 경로 | 내용 |
|---|---|
| `card/index.html` | 전체 평가사업 목록. ① 이력카드 수록 99개 사업(등급 추이·저성과·원문 수합·이행 회신·’26 열린재정) ② 열린재정 수록 중소기업지원사업평가 전체 사업(’21~’26, 338개). 검색·부처 필터·열 정렬, 사업명 클릭 시 카드로 이동 |
| `card/eval_history_card.html` | 완성 카드(데이터 내장, 단일 파일). 상단 선택 상자로 99개 사업 전환, `#p<세부사업ID>`로 직접 링크, '전체 사업 목록' 링크 |
| `card/examples/2030200_고용유지지원금.html` | 실제 데이터 적용 례(고용노동부 고용유지지원금) 단일 카드 |
| `docs/2030200_고용유지지원금.png` | 위 카드 화면 |
| `card/template.html` | 카드 서식·렌더링 로직(`__DATA__` 자리에 데이터 삽입) |
| `data/history.json` | xlsx 등급 + hwp 지적·권고·이행조치를 세부사업 단위로 결합한 데이터 |
| `tools/hwp_tables.py` | HWP 5.0 바이너리 표 → 셀(행·열·병합) JSON |
| `tools/build_dataset.py` | xlsx + 표 JSON → `history.json` (사업명 정규화 결합, 지적/권고/이행/완료일 분리) |
| `tools/build_card.py` | 템플릿 + 데이터(+예시 문안 파일) → 카드 HTML |
| `tools/build_index.py` | history.json + openfiscal_results.json → `card/index.html` |
| `data/sample_findings_3612300.json` | 마케팅지원사업 예시 문안(지적·권고·이행조치, `sample: true`) |
| `tools/fetch_openfiscal.py` | 열린재정 재정사업평가결과 수집(화면 내부 JSON 엔드포인트, 인증키 불필요, 연도별 재시도·캐시) |
| `data/openfiscal_results.json` | 열린재정 ’19~’26 재정사업평가결과 전 사업 7,086행(연도·평가제도·소관·회계·프로그램·세부사업·결과·유형) |

## 재생성

```bash
pip install olefile openpyxl
python3 -I tools/hwp_tables.py <개선사항 수합본.hwp> /tmp/tables.json
python3 -I tools/fetch_openfiscal.py 2019 2026 data/openfiscal_results.json /tmp/openfiscal_cache
python3 -I tools/build_dataset.py <등급추이.xlsx> /tmp/tables.json data/history.json data/openfiscal_results.json
python3 -I tools/build_card.py card/template.html data/history.json card/eval_history_card.html data/sample_findings_3612300.json
python3 -I tools/build_card.py card/template.html data/history.json card/examples/2030200_고용유지지원금.html --only 2030200   # 단일 사업 카드
python3 -I tools/build_index.py data/history.json data/openfiscal_results.json card/index.html   # 전체 사업 목록
```

## 실제 데이터 적용 례: 고용노동부 고용유지지원금 (세부사업 2030200)

□ 수합본에 지적·권고(5건)와 이행조치(5건)가 모두 실려 있는 사업으로, 예시 문안 없이 세 자료가 그대로 카드에 들어간 경우. 단일 카드 `card/examples/2030200_고용유지지원금.html`, 화면 `docs/2030200_고용유지지원금.png`

○ 1·2절 — xlsx 행 그대로: 기금 · 1995~계속 · 예산서 1045-350 · 분야 인력(’20 보호, ’26 회복) · 등급 ’19 미흡 → ’20 보통 → ’21 미흡 → ’22 보통 → ’23 개선필요 → ’24·’25 보통 → ’26 개선필요(저성과 4회, 연속 없음)
 - 타 재정사업평가제도(열린재정): 일자리사업평가 ’21 우수 · ’24 개선 · ’25 양호, 통합재정사업평가 ’26 감액(유형 일자리·중소기업). 중소기업지원사업평가 공개값(’21 미흡, ’23 개선, ’24·’25 보통)은 xlsx 등급과 4개 연도 모두 일치
○ 3절 — 2023년(’22년 실적) 개선필요 판정의 권고 5건과 고용부 회신 이행조치 5건이 같은 순서·같은 건수라 항목별로 행을 맞춰 대비(①~⑤ 번호, 완료일 배지)
 - ① 수요 감소에 따른 집행률 부진(77.7%) → 예산 조정 ’22.12월(597,621 → 197,220백만원)
 - ② 부정수급 대응 미흡(390건·12,307백만원) → 동일 IP 경고·계약만료자 자동 경보 등 전산 개선 ’23.7월
 - ③ 정책만족도 저조(76.4점, 분야 평균 80.7점) → 법·고시 개정으로 심사 절차 간소화·판단기준 단일화 ’24.2월
 - ④ 수혜기업 고용증감률 -14.2%·생존율 83.1% → 고용유지 장려기간 신설(6개월 내 10% 이상 고용조정 시 2년 신규지원 제한) ’24.2월
 - ⑤ 현장 의견수렴·정보제공 부족 → 담당자·사업주 간담회, 활용 안내서 배포 ’24.7월
 - ’19·’21년 미흡과 ’26년 개선필요는 수합 대상 연도(’23~’25 평가분)가 아니어서 '수합본 범위 외'로 표시
○ 4절 — 지적 원문이 수합된 연도가 2023년 하나뿐이라 연도 간 반복 판정은 '판정 불가'로 표시하고, 등급 이력상 ’19·’21·’23·’26년 저성과 반복을 우선 확인 과제로 제시
○ 5절 — 자동 생성된 확인 사항: ’26년 개선필요 권고의 이행 확인(이행조치 미회신), 4개 저성과 연도 사유의 동일성, 등급체계 개편 전후 합산(4회), 분야 변경(인력→보호→회복), ’26년 통합재정사업평가 '감액'과의 연계, ’24년 일자리사업평가 '개선' 이력

○ 시사점
 - ’23년 권고 5건이 ’24.7월까지 모두 이행 완료로 회신되었고 ’24·’25년 등급이 보통으로 회복되었으나 ’26년에 다시 개선필요로 떨어짐. ’26년 평가의 지적이 ’23년 권고 주제(집행률·부정수급·만족도·고용유지·현장소통)와 겹치는지가 평가위원의 핵심 확인 사항이며, ’26년 평가보고서 원문이 입력되면 4절에서 자동 대비됨

## 열린재정 연동 방식

□ 재정사업평가결과 화면(UOPKOBRA03)이 호출하는 내부 JSON 엔드포인트를 그대로 사용하여 연도별 전 사업 결과를 수집

○ 요청: `POST /op/ko/br/selectPgrvRsltList.do`, 본문 `{"searchDVO":{"evlAcntYr":"2026","offcCd":"","pfinBizEvlCd":""}}` (소관·평가제도 공란 = 전체)
 - 인증키 불필요, 연도당 1회 요청으로 전체 반환(2026년 2,616행). 서버가 간헐적으로 연결을 끊어 재시도와 캐시를 둠
 - 수록 평가제도: 재난안전사업평가·일자리사업평가·중소기업지원사업평가·국가균형발전사업평가·복권기금평가, ’26년부터 통합재정사업평가(유형: 보조사업·재난안전·중소기업·일자리)
 * 재정사업 자율평가 등급(EVL010)은 화면 코드상 비활성 항목으로 결과에 포함되지 않음
○ 결합: 사업명 정규화(공백·괄호·R&D·말미 '사업' 제거) 일치, 복수 후보는 소관 일치 우선. 현재명_(과거)과거명 병기 사업은 두 이름 모두 색인
 - 열린재정 '개선' 표기는 본 평가의 '개선필요'와 동일 등급으로 간주하여 정합성 대조
 - 한 연도에 복수 결과가 있으면 모두 표시(사업명 변경 전후 또는 중복 수록분)
○ 검증(2026-10-25): 중소기업지원사업평가 결과 ↔ xlsx 등급 251건 대조, 248건 일치·3건 불일치(농식품해외시장진출 ’24 개선필요/보통, 녹색혁신기업성장지원 ’21 미평가/보통·’24 개선필요/우수) → 카드 2절 주석과 5절 확인 사항에 노출
 - 소관이 다른 결합 11건은 부처 이관·개편(산업통상부, 기후에너지환경부)에 따른 것이나, 온실가스관리인프라구축의 ’24·’25 중소기업지원사업평가 행은 열린재정 소관이 기획재정부로 표기되어 동명 사업 혼입 가능성 점검 필요
 - 미결합 5개 사업(지역혁신생태계구축지원, 창의산업전문기술개발사업, 시스템산업미래성장동력(R&D), 과학치안공공연구성과실용화촉진시범사업(R&D), 장기사용석유저장시설안전관리융자)은 열린재정 공개 목록에 동일 사업명이 없어 별칭 등록으로 보완 가능
